
# Network Intrusion Detection and Security Alert System

## Project Description
This project is designed to detect suspicious network activities and generate security alerts.

## Technologies Used
- Python
- Flask
- Scapy
- HTML
- CSS

## Project Files
- app.py
- detector.py
- demo_run.py

## Installation

pip install -r requirements.txt

## Run Project

python app.py

## Purpose
To identify suspicious network traffic and improve network security awareness.
